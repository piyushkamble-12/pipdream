# Changelog

## Phase 2 — Visitor-powered dream workshop

- Kept V3 hero, project sections, visual identity, story scenes, toybox, Pip character reaction and secret moon.
- Expanded music box into a six-note composer with a 12-note limit, recorded-note chips, playback, stop, reset, mute handling and cleanup.
- Added three global lantern palettes (Warm Sunset, Moonlit Lavender, Midnight Blue), a miniature live lighting preview, and local persistence fallback.
- Upgraded dream delivery from one predetermined path to three actual SVG paths with destination/package choices and contextual status updates.
- Added **Build a Little Dream**, a signature interactive storytelling section with 27 deterministic story combinations, local decorative art, Pi​p messages, another-dream cycling and clipboard/manual-copy fallback.
- Restored discoverable navigation links on narrow screens instead of hiding navigation entirely.
- Switched essential image sources to bundled local SVG fallbacks. Optional helper replaces image `src` with downloaded local official PNGs.
- Improved reduced-motion handling, focus cues, announcements, audio stop handling, page-exit cleanup, and zero-backend privacy clarity.
- Refreshed README, submission draft and QA checklist; added offline browser smoke tests.
